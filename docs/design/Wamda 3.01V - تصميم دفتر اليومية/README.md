# ومضة 3.01V — تصميم مستقل لشاشة دفتر اليومية

هذه نسخة تصميمية مستقلة للمعاينة، منفصلة تماماً عن مشروع `WAMDA 3.0V`. لا تعتمد على الخادم أو قاعدة البيانات، ولا تغيّر أي ملف في المشروع الأصلي.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح. يفضّل استخدام Edge أو Chrome لمعاينة الحركة والاختصارات.

## ما تم تحسينه

- إعادة بناء كاملة للتجربة حول مفهوم «مركز قيادة العملية» بدلاً من بطاقات منفصلة.
- مسار بصري من أربع مراحل: العميل، نوع العملية، التفاصيل، ثم المراجعة والترحيل.
- لوحة سياق للعميل مع تصور دائري للأرصدة متعددة العملات.
- محرر مركزي يرفع المبلغ إلى مركز الاهتمام ويثبت شريط الأوامر في أسفل مساحة الإدخال.
- سجل نشاط حي على شكل تدفق زمني، مع نبض يومي ومؤشر إيقاع أسبوعي.
- وضع تركيز يخفي اللوحات الجانبية عند الحاجة لإكمال عملية طويلة.
- شريط عملية جديدة خفيف يحافظ على رؤية الشاشة الرئيسية أثناء الاختيار.
- زر عملية جديدة ثابت مع نافذة اختيارات سريعة.
- اختصارات `/` للبحث و`Ctrl + N` لعملية جديدة و`Alt + 1..6` للتنقل.
- ملخص يومي مختصر، أرصدة العميل، معاينة القيد، وسجل نشاط قابل للتصفية دون تشويش بصري.
- تفاعلات مستقلة للبحث، اختيار العميل، نوع العملية، التنبيهات، الحفظ، والتنظيف.
- حركة ضغط خفيفة وانتقالات غير مزعجة مع دعم اتجاه RTL.

## ملاحظة

البيانات الظاهرة تجريبية بهدف اختبار تجربة الاستخدام فقط. ربط هذه الواجهة بالـ API أو تحويلها إلى مكوّنات داخل المشروع الأصلي خطوة لاحقة منفصلة.
